## 2. 实现权重初始化

### 初始化策略

```python
class DecoderOnlyTransformer:
    def __init__(self, config):
        # ... 模型定义 ...
        self.apply(self._init_weights)  # ← 应用初始化
    
    def _init_weights(self, module):
        """
        初始化策略：
        - Embedding: N(0, init_std)  正态分布
        - Linear: Xavier/Glorot      均匀初始化
        - RMSNorm: 全1               初始化
        """
        if isinstance(module, nn.Embedding):
            nn.init.normal_(module.weight, mean=0.0, std=self.config.init_std)
        
        elif isinstance(module, nn.Linear):
            nn.init.xavier_uniform_(module.weight)
            if module.bias is not None:
                nn.init.zeros_(module.bias)
        
        elif isinstance(module, RMSNorm):
            nn.init.ones_(module.weight)
```

### 各模块的 reset_parameters 方法

```python
# RMSNorm
class RMSNorm:
    def reset_parameters(self):
        nn.init.ones_(self.weight)

# MultiHeadAttention
class MultiHeadAttention:
    def reset_parameters(self):
        for module in [self.W_Q, self.W_K, self.W_V, self.W_O]:
            nn.init.xavier_uniform_(module.weight)

# SwiGLU_FFN
class SwiGLU_FFN:
    def reset_parameters(self):
        for module in [self.gate_proj, self.up_proj, self.down_proj]:
            nn.init.xavier_uniform_(module.weight)

# DecoderBlock
class DecoderBlock:
    def reset_parameters(self):
        self.attn_norm.reset_parameters()
        self.attention.reset_parameters()
        self.ffn_norm.reset_parameters()
        self.ffn.reset_parameters()
```

## 3. 添加配置类

### TransformerConfig 定义

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class TransformerConfig:
    """Transformer 模型配置类"""
    
    # 模型结构参数
    vocab_size: int = 50000
    d_model: int = 512
    num_heads: int = 8
    num_layers: int = 6
    d_ff: Optional[int] = None  # 默认 4 * d_model
    max_seq_len: int = 2048
    
    # 正则化参数
    dropout: float = 0.1
    attn_dropout: float = 0.1
    ffn_dropout: float = 0.1
    emb_dropout: float = 0.1
    
    # 归一化参数
    eps: float = 1e-5
    
    # RoPE 参数
    rope_theta: float = 10000.0
    
    # 权重初始化参数
    init_std: float = 0.02
    
    # 其他参数
    tie_weights: bool = False  # 权重绑定
    
    def __post_init__(self):
        """参数验证和自动设置"""
        if self.d_ff is None:
            self.d_ff = 4 * self.d_model
        
        # 验证
        assert self.d_model % self.num_heads == 0
        assert 0.0 <= self.dropout <= 1.0
        assert self.vocab_size > 0
        assert self.num_layers > 0
```

### 使用方式

**v0 版本（旧）：**

1. **集中管理**：所有参数在一处定义
2. **类型安全**：使用 `@dataclass` 自动类型检查
3. **可扩展**：易于添加新参数
4. **可序列化**：可保存/加载配置
5. **默认值**：提供合理默认值

## 新增功能方法

### 1. get_num_params()
```python
def get_num_params(self, non_embedding: bool = True) -> int:
    """
    获取参数数量
    Args:
        non_embedding: 是否排除 embedding 层参数
    """
    n_params = sum(p.numel() for p in self.parameters())
    if non_embedding:
        n_params -= self.token_embedding.weight.numel()
    return n_params
```

## 改进点总结

### 1. Dropout 支持 ✅
- **位置**：Embedding, Attention (权重+输出), FFN
- **可配置**：4 种独立 dropout 率
- **自动切换**：train/eval 模式

### 2. 权重初始化 ✅
- **策略**：Embedding(Normal), Linear(Xavier), Norm(Ones)
- **可配置**：init_std 参数
- **统一应用**：`apply(self._init_weights)`

### 3. 配置类 ✅
- **集中管理**：TransformerConfig dataclass
- **类型安全**：自动类型检查
- **参数验证**：`__post_init__`
- **易扩展**：添加新参数方便

### 4. 单元测试 ✅
- **覆盖全面**：9 项测试
- **自动运行**：`run_unit_tests()`
- **验证正确性**：形状、数值、Dropout 效果
