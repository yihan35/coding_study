# Decoder-Only Transformer 架构详解

## 🎯 整体架构流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    Decoder-Only Transformer                      │
│                                                                  │
│  Input: Token IDs [batch_size, sequence_length]                 │
│                              │                                   │
│                              ▼                                   │
│         ┌────────────────────────────────────┐                  │
│         │      Token Embedding Layer         │                  │
│         │   [bsz, seq] → [bsz, seq, d_model] │                  │
│         └────────────────────────────────────┘                  │
│                              │                                   │
│                              ▼                                   │
│         ┌────────────────────────────────────┐                  │
│         │         RoPE Frequency             │                  │
│         │  precompute: [max_seq, head_dim/2] │                  │
│         └────────────────────────────────────┘                  │
│                              │                                   │
│                              ▼                                   │
│  ╔══════════════════════════════════════════════════╗          │
│  ║           Decoder Block × N Layers               ║          │
│  ║                                                   ║          │
│  ║  ┌─────────────────────────────────────────┐    ║          │
│  ║  │        1. Pre-Norm (RMSNorm)            │    ║          │
│  ║  │   x_norm = RMSNorm(x)                   │    ║          │
│  ║  └─────────────────────────────────────────┘    ║          │
│  ║                     │                            ║          │
│  ║                     ▼                            ║          │
│  ║  ┌─────────────────────────────────────────┐    ║          │
│  ║  │    2. Multi-Head Attention (MHA)        │    ║          │
│  ║  │                                         │    ║          │
│  ║  │  Q = W_Q(x_norm)  [bsz,seq,num_h,d_k]  │    ║          │
│  ║  │  K = W_K(x_norm)  [bsz,seq,num_h,d_k]  │    ║          │
│  ║  │  V = W_V(x_norm)  [bsz,seq,num_h,d_k]  │    ║          │
│  ║  │           │                              │    ║          │
│  ║  │           ▼                              │    ║          │
│  ║  │  ┌──────────────────────┐               │    ║          │
│  ║  │  │   Apply RoPE to Q,K  │               │    ║          │
│  ║  │  │  Q_rot, K_rot        │               │    ║          │
│  ║  │  └──────────────────────┘               │    ║          │
│  ║  │           │                              │    ║          │
│  ║  │           ▼                              │    ║          │
│  ║  │  Attention = Softmax(Q·Kᵀ/√d_k) · V    │    ║          │
│  ║  │    (with Causal Mask)                   │    ║          │
│  ║  │           │                              │    ║          │
│  ║  │           ▼                              │    ║          │
│  ║  │  Output = W_O(Attention)                │    ║          │
│  ║  └─────────────────────────────────────────┘    ║          │
│  ║                     │                            ║          │
│  ║                     ▼                            ║          │
│  ║  ┌─────────────────────────────────────────┐    ║          │
│  ║  │      3. Residual Connection             │    ║          │
│  ║  │   h = x + Attention(RMSNorm(x))         │    ║          │
│  ║  └─────────────────────────────────────────┘    ║          │
│  ║                     │                            ║          │
│  ║                     ▼                            ║          │
│  ║  ┌─────────────────────────────────────────┐    ║          │
│  ║  │        4. Pre-Norm (RMSNorm)            │    ║          │
│  ║  │   h_norm = RMSNorm(h)                   │    ║          │
│  ║  └─────────────────────────────────────────┘    ║          │
│  ║                     │                            ║          │
│  ║                     ▼                            ║          │
│  ║  ┌─────────────────────────────────────────┐    ║          │
│  ║  │       5. SwiGLU FFN (Qwen3)           ║          │
│  ║  │                                         │    ║          │
│  ║  │  gate = Swish(Gate_proj(h_norm))       │    ║          │
│  ║  │  up   = Up_proj(h_norm)                │    ║          │
│  ║  │  ffn_out = Down_proj(gate ⊙ up)        │    ║          │
│  ║  │                                         │    ║          │
│  ║  │  [d_model] → [d_ff] → [d_model]        │    ║          │
│  ║  └─────────────────────────────────────────┘    ║          │
│  ║                     │                            ║          │
│  ║                     ▼                            ║          │
│  ║  ┌─────────────────────────────────────────┐    ║          │
│  ║  │      6. Residual Connection             │    ║          │
│  ║  │   output = h + FFN(RMSNorm(h))          │    ║          │
│  ║  └─────────────────────────────────────────┘    ║          │
│  ║                                                   ║          │
│  ╚══════════════════════════════════════════════════╝          │
│                              │                                   │
│                              ▼                                   │
│         ┌────────────────────────────────────┐                  │
│         │      Final RMSNorm Layer           │                  │
│         └────────────────────────────────────┘                  │
│                              │                                   │
│                              ▼                                   │
│         ┌────────────────────────────────────┐                  │
│         │    Language Model Head (LM Head)   │                  │
│         │  Linear: [bsz,seq,d_model]         │                  │
│         │       → [bsz,seq,vocab_size]       │                  │
│         └────────────────────────────────────┘                  │
│                              │                                   │
│                              ▼                                   │
│              Logits [bsz, seq, vocab_size]                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

                              │
                              ▼
            ┌──────────────────────────────────┐
            │       Generation Phase           │
            │       (Inference Only)           │
            │                                  │
            │  1. Take last token logits       │
            │  2. Apply temperature            │
            │  3. Top-P (Nucleus) Sampling     │
            │  4. Sample next token            │
            │  5. Append and repeat            │
            └──────────────────────────────────┘
```

## 🔬 核心组件详解

### 1. RoPE (Rotary Position Embedding) 详解

```
输入: Q, K ∈ ℝ^(bsz × seq × num_heads × head_dim)

步骤:
1. 计算频率 θ_i = 10000^(-2i/d), i ∈ [0, d/2)
   
2. 计算角度矩阵:
   Θ = [pos_0, pos_1, ..., pos_seq-1]ᵀ × [θ_0, θ_1, ..., θ_d/2-1]
   
3. 转换为复数:
   freqs_cis = e^(i·Θ) = cos(Θ) + i·sin(Θ)
   
4. 应用旋转 (复数乘法):
   Q_rot = Q_complex × freqs_cis
   K_rot = K_complex × freqs_cis

优势:
✓ 相对位置编码
✓ 外推性好 (可处理比训练更长的序列)
✓ 不增加参数量
✓ 旋转不变性
```

### 2. RMSNorm (Root Mean Square Normalization) 详解

```
公式: RMSNorm(x) = (x / RMS(x)) · γ

其中:
  RMS(x) = √(1/d · Σ x_i²)
  γ: 可学习的缩放参数

对比 LayerNorm:
  LayerNorm: y = (x - μ) / σ · γ + β
  RMSNorm:   y = x / RMS(x) · γ

优势:
✓ 计算更简单 (不需要计算均值和方差)
✓ 训练更快
✓ 性能相当或更好
✓ Llama、Qwen 等模型使用
```

### 3. Multi-Head Attention 详解

```
输入: x ∈ ℝ^(bsz × seq × d_model)

1. 线性投影:
   Q = xW_Q  ∈ ℝ^(bsz × seq × d_model)
   K = xW_K  ∈ ℝ^(bsz × seq × d_model)
   V = xW_V  ∈ ℝ^(bsz × seq × d_model)

2. 分割成多头:
   Q → [bsz, num_heads, seq, head_dim]
   K → [bsz, num_heads, seq, head_dim]
   V → [bsz, num_heads, seq, head_dim]
   
   其中 head_dim = d_model / num_heads

3. 应用 RoPE (仅 Q 和 K):
   Q_rot, K_rot = apply_rope(Q, K, freqs_cis)

4. 计算注意力分数:
   scores = (Q · Kᵀ) / √head_dim
   scores ∈ ℝ^(bsz × num_heads × seq × seq)

5. 应用因果掩码:
   Mask = [[1, 0, 0, 0],
           [1, 1, 0, 0],
           [1, 1, 1, 0],
           [1, 1, 1, 1]]  (下三角矩阵)
   
   scores = scores.masked_fill(mask==0, -∞)

6. Softmax 归一化:
   attn_weights = softmax(scores, dim=-1)

7. 加权求和:
   output = attn_weights · V
   output ∈ ℝ^(bsz × num_heads × seq × head_dim)

8. 合并多头:
   output → [bsz, seq, d_model]

9. 输出投影:
   output = output · W_O
```

### 4. SwiGLU FFN (Qwen3 架构) 详解

```
输入: x ∈ ℝ^(bsz × seq × d_model)

架构:
┌─────────────┐
│      x      │
└──────┬──────┘
       │
   ┌───┴────┐
   │        │
   ▼        ▼
Gate_proj  Up_proj
   │        │
d_model    │
   │        │
   ▼        │
 Swish   d_ff
(SiLU)     │
   │        ▼
   │     d_ff
   │        │
   └───┬────┘
       │ (element-wise multiply)
       ▼
   gate ⊙ up
       │
       ▼
   Down_proj
       │
       ▼
    d_model
       │
       ▼
    output

公式:
  gate = Swish(W_gate · x)
  up = W_up · x
  output = W_down · (gate ⊙ up)

其中:
  Swish(x) = x · σ(x) = x · sigmoid(x)
  ⊙ 表示逐元素乘法 (Hadamard product)

参数:
  W_gate: [d_model, d_ff]
  W_up:   [d_model, d_ff]
  W_down: [d_ff, d_model]
  
  通常 d_ff = 4 × d_model

优势:
✓ GLU 变体,性能优于传统 FFN
✓ 门控机制控制信息流
✓ Swish 激活函数平滑且无上界
```

### 5. Top-P (Nucleus) Sampling 详解

```
输入: logits ∈ ℝ^vocab_size

步骤:
1. 转换为概率:
   probs = softmax(logits / temperature)

2. 降序排序:
   sorted_probs, sorted_indices = sort(probs, descending=True)

3. 计算累积概率:
   cumsum_probs = cumsum(sorted_probs)

4. 找到累积概率超过 p 的位置:
   mask = cumsum_probs > p

5. 过滤低概率 token:
   filtered_probs = probs
   filtered_probs[mask] = 0

6. 重新归一化:
   filtered_probs = filtered_probs / sum(filtered_probs)

7. 采样:
   next_token = sample(filtered_probs)

示例 (p=0.9):
  原始概率: [0.4, 0.3, 0.15, 0.1, 0.05]
  累积概率: [0.4, 0.7, 0.85, 0.95, 1.0]
  选择范围: [✓,   ✓,   ✓,    ✗,   ✗]
  (前3个累积到0.85 < 0.9, 第4个超过)

优势:
✓ 动态调整候选集大小
✓ 避免采样到低质量 token
✓ 保持多样性
```

## 🎨 特性对比

| 特性 | Encoder-Decoder | Decoder-Only |
|-----|----------------|--------------|
| **架构** | 双栈 | 单栈 |
| **注意力** | Self + Cross | Self only |
| **掩码** | 双向 + 因果 | 因果 |
| **应用** | 翻译、摘要 | 语言生成 |
| **代表模型** | T5, BART | GPT, LLaMA |
| **参数效率** | 较低 | 较高 |

## 💡 关键设计决策

1. **Pre-Norm vs Post-Norm**: 选择 Pre-Norm
   - ✓ 训练更稳定
   - ✓ 梯度流动更好
   - ✓ 现代大模型标准

2. **RoPE vs Sinusoidal**: 选择 RoPE
   - ✓ 相对位置编码
   - ✓ 外推性好
   - ✓ 不占用额外参数

3. **RMSNorm vs LayerNorm**: 选择 RMSNorm
   - ✓ 计算更快
   - ✓ 性能相当
   - ✓ 现代大模型趋势

4. **SwiGLU vs GELU**: 选择 SwiGLU
   - ✓ 性能更好
   - ✓ Qwen、LLaMA 使用
   - ✓ 门控机制更灵活

5. **Top-P vs Top-K**: 选择 Top-P
   - ✓ 动态调整
   - ✓ 质量更稳定
   - ✓ 工业界主流

---

**总结**: 这是一个现代化的 Decoder-Only Transformer 实现，整合了最新的技术进展，适合用于语言生成任务。
