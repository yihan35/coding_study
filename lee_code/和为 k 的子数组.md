## 1. 问题背景
我们要解决的问题是：**给一个数组 `nums` 和一个目标值 `k`，找出有多少个连续子数组的和恰好等于 `k`**。

举个例子：
- `nums = [1, 2, 3]`，`k = 3`
- 满足条件的子数组有 `[3]` 和 `[1, 2]` → 答案是 `2`。

---

## 2. 核心思路：前缀和 + 哈希表
### 前缀和是什么？
我们定义 `pre[i]` 为数组前 `i` 个元素的和（`pre[0] = 0`，`pre[1] = nums[0]`，`pre[2] = nums[0] + nums[1]`，以此类推）。

比如 `nums = [1, 2, 3]`，前缀和数组就是：
`pre = [0, 1, 3, 6]`

### 子数组和与前缀和的关系
一个从 `i` 到 `j` 的子数组的和，等于 `pre[j+1] - pre[i]`。
所以，如果我们想让 `pre[j+1] - pre[i] = k`，等价于找 `pre[i] = pre[j+1] - k`。

换句话说：
> 当我们遍历到 `pre[j+1]` 时，只需要知道之前出现过多少次 `pre[j+1] - k`，就有多少个满足条件的子数组以 `j` 结尾。

---

## 3. 用生活例子理解
假设你每天都记自己的总存款（前缀和）：
- 第 0 天（初始）：`pre[0] = 0` 元
- 第 1 天：`pre[1] = 1` 元
- 第 2 天：`pre[2] = 3` 元
- 第 3 天：`pre[3] = 6` 元

现在想找“哪几天之间的存款变化恰好是 3 元”（`k=3`）。
- 第 3 天存款是 6 元，我们想找之前有没有 `6 - 3 = 3` 元的记录。
- 发现第 2 天有 3 元，所以第 2 天到第 3 天的变化是 3 元（子数组 `[3]`）。
- 再看第 2 天存款是 3 元，找 `3 - 3 = 0` 元的记录。
- 发现第 0 天有 0 元，所以第 0 天到第 2 天的变化是 3 元（子数组 `[1, 2]`）。
- 这样就找到了 2 个满足条件的子数组。

---

## 4. 代码逐行解释

```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        # 用哈希表记录前缀和出现的次数，初始时 pre=0 出现了 1 次
        cnt = defaultdict(int)
        n = len(nums)
        # 前缀和数组，pre[0]=0，pre[1]=nums[0]，pre[2]=nums[0]+nums[1]...
        pre = [0] * (n + 1)
        
        # 计算前缀和数组
        for i in range(1, n + 1):
            pre[i] = pre[i - 1] + nums[i - 1]
        
        ans = 0
        # 遍历所有前缀和
        for p in pre:
            # 之前出现过多少个 p - k，就有多少个子数组和为 k
            ans += cnt[p - k]
            # 把当前前缀和 p 的出现次数加 1
            cnt[p] += 1
        
        return ans
```

### 关键步骤拆解
1.  **初始化哈希表 `cnt`**：
    - 它的作用是记录每个前缀和出现的次数。
    - 初始时 `cnt[0] = 1`，因为 `pre[0] = 0` 是我们的起点。

2.  **计算前缀和数组 `pre`**：
    - `pre[0] = 0`，`pre[1] = nums[0]`，`pre[2] = nums[0] + nums[1]`，依此类推。
    - 这样我们就把所有可能的前缀和都存了下来。

3.  **遍历前缀和数组，统计答案**：
    - 对于当前前缀和 `p`，我们看 `cnt` 里已经有多少个 `p - k`。
    - 这个数量就是以当前位置结尾、和为 `k` 的子数组个数，加到 `ans` 里。
    - 然后把当前前缀和 `p` 加入 `cnt`，供后面的前缀和查询使用。

---

## 5. 用例子跑一遍代码
以 `nums = [1, 2, 3]`，`k = 3` 为例：
1.  `pre = [0, 1, 3, 6]`
2.  初始化 `cnt = {0:1}`，`ans = 0`
3.  遍历 `pre`：
    - 第一个 `p = 0`：`ans += cnt[0 - 3] = cnt[-3] = 0` → `ans = 0`；`cnt[0]` 变为 2
    - 第二个 `p = 1`：`ans += cnt[1 - 3] = cnt[-2] = 0` → `ans = 0`；`cnt[1] = 1`
    - 第三个 `p = 3`：`ans += cnt[3 - 3] = cnt[0] = 2` → `ans = 2`；`cnt[3] = 1`
    - 第四个 `p = 6`：`ans += cnt[6 - 3] = cnt[3] = 1` → `ans = 3`；`cnt[6] = 1`
4.  返回 `ans = 2`（和我们之前的手动计算一致）
